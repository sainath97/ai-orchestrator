# Quality gates

G1 purpose and diff are clear
G2 no secrets or real sensitive data added
G3 no unrelated edits
G4 build ran or reason is documented
G5 tests ran or reason is documented
G6 risk tier and rationale are recorded
G7 rollback is documented when production behavior changes
G8 reviewers are listed
G9 multi-repository order is recorded when relevant
G10 PR body is complete
