# Prepare PR workflow

1. Confirm the target child path under `repos/`.
2. Read the parent and child `PROJECT_CONTEXT.md` files.
3. Read the ticket through the configured MCP connector or use the manual fallback.
4. Review `git diff` and `git status` in the child repository.
5. Run the narrowest meaningful checks available.
6. Invoke reviewers according to risk.
7. Draft the PR body and list unverified items.
8. Leave commit, push, and merge actions to an authorized human unless explicitly instructed.
