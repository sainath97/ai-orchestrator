# PR review matrix

| Risk or change | Required reviewers |
| --- | --- |
| Every change | verifier, test-strategist |
| Architecture or cross-package boundary | architect-reviewer |
| Auth, privacy, secrets, public exposure | security-reviewer, privacy-reviewer |
| CI/CD, infrastructure, production release | release-reviewer |
| Logging, metrics, alerting | observability-reviewer |
| Integrator-facing UX or API clarity | ux-reviewer |
