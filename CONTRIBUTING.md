Contributing
============

This repo accepts changes only to governance, rules, agents, skills, scripts, and docs. Application code changes must be contributed to child repositories.

When to PR here vs child repo:
- Parent repo: rules, skills, connectors, scripts, docs, repository catalog.
- Child repo: application code, tests, CI that touch app behavior.

See `docs/guides/story-to-pr-guide.md` for the end-to-end flow.
